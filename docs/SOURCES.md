A link is a reference starting point, **not evidence that the generator has been audited against that page or validated against a live system**. The links use vendor-maintained or project-maintained documentation where available. Pages labelled “latest” may change independently of this repository.

Terraform constraints below come from [`src/providers.json`](../src/providers.json) and are emitted by the generators as `~> version`. Other output tools generally have no version pin; the Azure Firewall PowerShell script specifies an Az.Network minimum version. Use documentation matching the version installed in your environment. Unless noted otherwise, generated syntax has not been validated against a live product.

## Keeping this index current

- When adding or changing a generated output, update its row with the product documentation and the exact tool resource, module, cmdlet, API, or CLI reference used by the generator.
- Record versions from the generator's actual constraints or API versions. If a version is not pinned, say so instead of implying a compatibility guarantee.
- Treat live execution, schema validation, and documentation review as separate validation activities. Update the status text only when that validation has actually been performed, and retain explicit gaps for references that cannot be confirmed.
- Keep Terraform provider versions consistent with [`src/providers.json`](../src/providers.json); the provider update script refreshes versions within each configured major version.
